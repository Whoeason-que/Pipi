# 变体 A · 精工暗台（Precision）

## 设计立场

现有方案（「方案 C · 工具台」）的**精修版**：不改三栏信息架构，把散落在各处的粗糙感逐项打磨。
核心思路是「不推翻，只抛光」—— 风险最低、可局部采用。

## 关键选择

- **手写线性 SVG 图标（15 个）**：替换全部字符符号（`← ⚙ ✕ ▥ ⑂ ＋ ☰ ▶ ■`）。
  stroke 1.6px 统一视觉重量，hover/active 态跟随语义色。这是观感提升最大的一项。
- **角色标签从「全大写色块」改为「语义点 + 小写 mono 胶囊」**：user 蓝点、tool 琥珀点、
  错误红点，去掉背景色块（色块是 AI 生成 tell 之一，且在小字号下噪）。
- **用户消息行轻微 accent 渐变底色**：一眼区分「我问的」和「它做的」，不引入气泡。
- **composer 改为独立圆角容器**：聚焦时 accent 光环，与上方日志流分离，停止按钮语义红。
- **侧栏会话操作按钮 hover 才显示**：降低常态噪音；搜索框加放大镜图标。
- **顶栏标签改为胶囊式**（取代底部描边），状态栏保持单行分段仪表。

## Trade-offs

- 强在：对现有代码侵入最小（大多数是 CSS + 图标替换）；观感提升确定性高。
- 弱在：信息架构无变化，「工具感」依然强 —— 适合作为基线，不解决更深的体验问题。

## 适合场景

想立刻提升 Pipi 的完成度、且不想冒险重构布局时，选这个方向落地。
