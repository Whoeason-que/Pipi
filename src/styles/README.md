# 样式归属

样式以职责和功能为边界。一个功能无论出现在主区、侧栏还是弹窗，其专属样式都由同一份文件拥有。

- `foundation/`：主题令牌、全局重置、基础排版、共享动画和无障碍偏好。
- `components/`：`controls.css` 拥有控件与共享内容行为，`forms.css` 拥有表单和选择器，`overlays.css` 拥有反馈与弹层，`navigation.css` 拥有导航和工具栏，`panels.css` 拥有面板外壳。
- `features/`：Agent 身份与目录、会话活动、配置、消息、工具调用、输入与待发队列、搜索、技能、偏好、供应商、远程访问、工作区、论坛、文件、Git 与 Agent 统计。
- `content/`：Markdown 正文、代码块和语法高亮，在消息、论坛与文件预览中共用。

`../styles.css` 是唯一聚合入口，按基础、共享组件、功能内容的顺序加载。共享组件拥有默认外观和交互状态；功能文件拥有布局和语义变体，例如输入区的发送按钮、供应商表单的操作栏。

媒体查询与触屏规则放在所属文件中，通常位于该功能的常规规则之后。全局减少动画偏好属于 `foundation/base.css`；导航抽屉属于 `components/navigation.css`；检查器抽屉属于 `components/panels.css`。不另设统一的响应式或页面覆盖文件。

复用以实际职责为依据：多个位置使用同一个控件才抽取共享样式，相同的 `display`、间距或颜色不足以构成新抽象。功能扩展时按独立的改动理由拆分，例如 Agent 文件编辑与工作区文件预览分别维护。

先使用已有的 `.btn`、`.icon-btn`、`.surface`、`.badge`、`.field` 等控件样式，以及以下共享内容行为，再补充功能变体：

- `.truncate`：单行文本省略；功能样式负责可用宽度和伸缩约束。
- `.caption`：辅助文字的颜色与字号；上下文中的字号差异由功能变体覆盖。
- `.content-pane`：可伸缩、允许收缩的主内容列；功能样式负责滚动和内边距。
- `.page-scroll`：页面级滚动主体（统一留白、居中与滚动条占位）；`.page-section` 提供分区之间的默认间距。
- `.page-heading`：页面标题区；`.page-heading-intro`、`.page-heading-spaced`、`.page-heading-actions` 分别负责标题列、标题后间距与右侧操作组。
- `.section-heading`：分区标题行（标题 + 计数/提示）；`.section-heading-ruled` 追加细分隔线，`.section-count` 是计数徽标。
- `.empty-state`：居中的空状态内容列；`.empty-card` 是带边框/留白的空状态卡片（`.compact` 为横向紧凑变体），`.empty-icon` 是卡片内的图标块。
- `.icon-tile`：方形图标容器；通过 `--tile-size`、`--tile-icon-size` 指定容器和图标尺寸，功能样式负责颜色、边框和圆角。

共享类显式加在组件的 `className` 上，不通过跨功能选择器清单关联。关联紧密的小段样式合并维护，例如模型切换与输入区、Agent 文件编辑与配置、文件树与内容预览；不为每个子组件单独建立 CSS 文件。

移动规则时保持选择器、声明、媒体条件和有效的级联关系。特别留意同一元素上的公共类与功能类、重复的媒体条件，以及相同优先级的简写和长写属性；文件归属改变不应顺便改变界面表现。
