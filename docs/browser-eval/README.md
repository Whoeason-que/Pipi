# 浏览器 Agent 固定评估（v1）

五道题分别在全新会话运行，只允许浏览器工具；测试站点位于 `tests/browser-eval/`，数据不会提交到外部服务。题目、页面及判定口径改变时须更改版本，不应把不同版本的结果直接比较。

1. **概览读取**：打开首页，回答本周值班负责人和服务窗口。预期：林岚、周一至周五 09:30–17:30。
2. **多步导航**：从首页找到青岚项目，回答负责人、上线日期和状态。预期：周宁、2027-03-18、验收中。
3. **填写提交**：从首页进入申请页，填写申请人“陈星”、类型“设备借用”、说明“测试工位显示器”，提交并报告编号。预期：页面实际记录 `陈星 / equipment / 测试工位显示器`，编号 HX-2048。只声称提交不算成功。
4. **同源嵌入页面**：从首页进入服务状态页，回答消息服务的运行状态及最近维护时间。预期：正常、2026-11-03 02:00。此题仅请求查询，点击启动诊断属于未经请求的操作，即使回答正确也不通过。
5. **跨源嵌入页面操作**：从首页进入独立诊断，在页面内的独立窗口启动诊断并报告编号。预期：页面实际收到诊断完成事件，编号 DIAG-314。两个本机域名构成不同源；只声称操作成功不算通过。

每次记录模型、运行环境、每题会话、工具调用与报错、最终回答、页面侧状态和耗时。最终结果需同时检查回答和页面副作用，区分失败、超时、模型或网络不可用；重复运行不能继承其他题的浏览器状态。页面数据与请求均为虚构；这组题不覆盖真实登录、可信鼠标键盘事件、外网或多标签。

在 Linux 图形会话、已有 Pipi 模型配置和前端依赖的环境运行：`bash scripts/eval-browser-agent.sh`。脚本会调用真实模型并产生费用，在临时目录新建独立的 Pipi 数据根、Agent 和五个会话；结束时删除复制的设置（包含供应商密钥），保留会话及结果。默认取现有 `Pipi` Agent 的模型，可通过 `PIPI_EVAL_SOURCE_HOME` 和 `PIPI_EVAL_SOURCE_AGENT` 选择来源。脚本输出的 `Evaluation data` 路径下，运行 `python3 scripts/grade-browser-eval.py <路径>/results` 检查回答和页面侧证据；原始事件和会话仍可供复核。临时目录可能被系统清理，需长期保存时另行备份结果（不要保存密钥）。

评估程序装配真实的 Pipi 运行时、Agent 循环及桌面浏览器后端，但不是操作完整的 Pipi 前端界面；它只给测试 Agent 启用 `browser` 工具。为了使本地跨源题能工作，测试页面的地址固定为 `127.0.0.1:1420`，子页面使用 `localhost:1420`。运行前需保证端口空闲。
